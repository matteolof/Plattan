# Plattan v116 – smart genomskinlighet

- Byggplattor på den egna och andra spelares tomter är ogenomskinliga på långt avstånd.
- Inom 12 rutor blir plattorna genomskinliga som tidigare (47 % opacitet).
- Genomskinligheten behålls tills avståndet överstiger 16 rutor, för att undvika flimmer.
- Kontroll var 400:e millisekund, inte varje bildruta. Befintliga plattor återanvänds utan att byggas om.
- 250 rutors sikt och affärernas optimering från v115 behålls.

Ersätt filerna i GitHub och låt Render uppdateras. Testa prestanda med stora byggen och två enheter.
