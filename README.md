Plattan Online v19 – byggmatris

Byggknappen öppnar nu en gemensam matris med fyra kolumner och åtta rader.
Stående till vänster, liggande till höger. Trianglarna visas i fyra varianter
för varje riktning. Längst ned finns färgväljare och rivknapp.
